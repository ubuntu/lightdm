# Security Policy

Specific information on supported versions will be determined soon. For now, any mainstream distribution that is maintaining a version of LightDM in its repositories, should be considered to be maintained.

## Reporting a Vulnerability

You can report vulnerabilities by emailing the maintainers of LightDM, or by sending a private message via Matrix. Please include an explanation of the bug and a proof of concept.

**The [contribution policy](CONTRIBUTING.md) still applies.**
